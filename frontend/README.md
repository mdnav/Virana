# 🌿 Virana

### AI-Powered Cultural Heritage Preservation & Exploration Platform

> **Discover • Learn • Contribute • Verify • Preserve**

Virana is an **AI-powered, interactive, multilingual cultural heritage platform** designed to help people discover, document, experience, and preserve India's rich tangible and intangible cultural heritage.

From monuments, temples, forts, historical places, traditional dances, music, languages, food, spices, festivals, rituals, folk stories, arts and crafts to oral traditions — **Virana brings cultural knowledge, communities, geography, and intelligent technology together in one connected digital ecosystem.**

# 📖 Overview

India's cultural landscape is extraordinarily diverse.

Thousands of communities preserve unique traditions, languages, festivals, art forms, food practices, rituals, crafts, stories, and historical knowledge.

However, this information is often fragmented across:

* Cultural institutions
* Government resources
* Museums
* Research publications
* Digital archives
* Regional communities
* Individual knowledge holders

This makes it difficult for people to discover lesser-known heritage, understand regional variations, contribute local knowledge, or access cultural information in their preferred language.

**Virana is designed to bridge this gap.**

The platform combines:

```text
GEOGRAPHY
    +
CULTURAL KNOWLEDGE
    +
COMMUNITY
    +
ARTIFICIAL INTELLIGENCE
    +
MULTILINGUAL ACCESS
    +
DIGITAL PRESERVATION
```

into a single cultural heritage ecosystem.

# 🔎 Intelligent Duplicate Detection

Community contributions may overlap with existing records.

Virana can identify potentially similar submissions using:

* Text similarity
* Semantic similarity
* Location similarity
* Existing heritage records
* Media information where applicable

However:

> **Similarity does not necessarily mean duplication.**

Two communities may share similar traditions while maintaining meaningful differences.

The system should therefore assist moderation rather than automatically deleting similar contributions.

# 🛡️ Cultural & Data Integrity

Cultural information requires additional care because traditions can vary significantly between communities.

Virana follows several principles:

### Preserve Context

Do not remove regional differences simply to create a generalized description.

### Preserve Original Content

Where possible, preserve the original language, audio, contribution, and cultural context.

### Source Awareness

Distinguish between:

* Official sources
* Research sources
* Verified information
* Community contributions
* AI-generated interpretation

### Respect Attribution

Contributors and external sources should receive appropriate attribution.

### Avoid AI Overclaiming

AI-generated information should not automatically be treated as factual.

### Community Corrections

Users should have mechanisms to report inaccurate or incomplete information.

# 🔬 Research & Data Philosophy

Virana is designed to combine:

**Institutional Knowledge + Open Data + Research + Community Knowledge**

rather than relying on a single information source.

The platform should maintain provenance wherever possible.

Each record can retain:

```text
Source
 ↓
Source URL
 ↓
Attribution
 ↓
License
 ↓
Verification Status
 ↓
Last Updated
```

This creates a more transparent cultural knowledge ecosystem.

# 🚀 Getting Started

## Prerequisites

Install the following before starting:

* Git
* Node.js
* Java
* Maven
* Python
* PostgreSQL
* Docker
* Docker Compose

---

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/virana.git
```

---

## 2. Navigate to the Project

```bash
cd virana
```

---

## 3. Configure Environment Variables

Create environment configurations for:

* Database
* Authentication
* AI services
* External APIs
* Object storage
* Map services

Use `.env.example` as the configuration reference.

**Never commit passwords, API keys, JWT secrets, or other credentials to GitHub.**

---

## 4. Start Infrastructure

```bash
docker compose up -d
```

---

## 5. Start the Backend

```bash
cd backend
```

Run the Spring Boot application using the project's configured Maven command.

---

## 6. Start the AI Service

```bash
cd ai-service
```

Install the required Python dependencies and start the FastAPI service.

---

## 7. Start the Frontend

```bash
cd frontend
npm install
npm run dev
```

The development server will provide the local frontend URL.

> Detailed installation instructions will be expanded as the system architecture stabilizes.
